# KeyPet — карманный зоопарк

Магазин акриловых брелоков: авторские мультяшные персонажи и брелоки с питомцем покупателя.
Старт — Одинцово / Москва, продажи через Авито, TikTok и Telegram.

## Утром — с чего начать (30 минут)

1. Открой сайт, посмотри дизайны. Каких не хватает или какие убрать?
2. Прочитай `docs/1-dengi.md` и покажи родителям: там весь бюджет (~6 000 ₽) и риски.
3. Вместе с родителями заведите Авито и Telegram на имя магазина (шаги в `docs/2-zapusk.md`).
4. Отправь сообщение в 3–5 типографий (шаблон в `docs/2-zapusk.md`) и сравни цены.
5. Сними первое видео, пока ждёшь ответы: «рисую брелоки для своего магазина» (`docs/4-tiktok.md`, идея №1).

## Как поменять сайт

- Контакты: в `site/template.html` найди `const CONTACT` и впиши ник Telegram, потом `python3 site/build.py`.
- Цены: там же `PRICE`, `SET3`, `PET` (и текст в карточках в `site/build.py`).
- Новый дизайн: добавь его в `tools/make_designs.py`, запусти его, затем `site/build.py`.
- Бесплатно выложить сайт в интернет: GitHub Pages, Netlify или Cloudflare Pages (папка `site/`).
