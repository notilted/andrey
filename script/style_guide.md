# «17 минут» — визуальный стандарт (по референсу)

Референс: 79 с, 576×1024, 30 fps; кадры изучены с шагом 1 с (79 кадров), склейки — 20,8 с и 50,4 с.

**Палитра (снята пипеткой):** небо `#080b14 → #101723 → #18202e`, земля `#0a0d14`, фасады `#222a38`,
тёмные окна `#141a24`, тёплый свет `#f2b448` / `#f3e083`, луна `#b0ab9d`, красный акцент `#d85445`, текст `#f2f2ee`.

**Принципы:**
- Плоский вектор без обводок, 2–3 тона на объект, мягкая виньетка и плёночное зерно.
- Люди в окнах — тёмные силуэты на жёлтом свете; в кадрах крупнее — персонажи с простой мимикой и контровым светом.
- Здания в разрезе (кукольный дом): межэтажные плиты, соседние этажи видны сверху и снизу.
- Композиция 9:16: действие в верхних ~60 % кадра, нижняя треть уходит в черноту — там субтитры.
- Субтитры: Montserrat 900, ЗАГЛАВНЫЕ, 64 px, до двух строк, слова «загораются» по ходу речи, ключевые — жёлтым.
- Плашки-ярлыки (жёлтые / красные / белые) с наклоном 1–3° и «выпрыгиванием»; статус-строка вверху слева («23:41 • МОСКВА»).
- Камера: медленный проезд с параллаксом (небо 0,15 / даль 0,35 / средний план 0,65 / передний 1,0), наезд в окно, переход через затемнение.
- Темп: смена плана каждые 2–4 с, анимация появления 8–12 кадров, кривая ease-out.
